Quick compiles and executes this C program with local evidence-guided tuning and direct Clang -O3, using the arguments and stdin above. It measures four candidates and confirms the winner in five paired rounds. No GPT or benchmark lookup. Provide main and deterministic output. Each execution is limited to 2 seconds and the quick comparison has a 30-second budget. Understandable uses GPT-6 Luna for compile-only inspection and explanation; it sends source and compiler output to OpenAI and uses API credits.

The full benchmark is separate: recognized bundled source runs 20 candidates per strategy and repeated correctness-checked timings. A runtime such as 215 ms is one execution of a compiled program, not the total experiment duration. Compilation time does not measure program speed.
